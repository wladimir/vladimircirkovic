# vladimircirkovic.com

The static one-page personal site for Vladimir Ćirković, hosted on GitHub Pages at [vladimircirkovic.com](https://vladimircirkovic.com/). It has no JavaScript, build step, or dependencies.

## Files

- `index.html` contains the page, styles, SEO metadata, and structured data.
- `404.html` is the custom not-found page.
- `VladimirCirkovicResume.pdf` is the linked résumé.
- `og-image.png` is the 1200×630 social sharing image.
- `favicon.svg`, `favicon.ico`, and `apple-touch-icon.png` are the site icons.
- `robots.txt` and `sitemap.xml` provide crawler metadata.
- `CNAME` configures the custom domain for GitHub Pages.

## Deploying

GitHub Pages serves the repository root directly. Push the finished changes to `main`; no build command or generated site directory is required.

## Replacing the résumé

Export the new résumé as `VladimirCirkovicResume.pdf` and replace the existing file without changing its name. Preserve meaningful PDF metadata, especially the Title (`Vladimir Ćirković — Résumé`) and Author (`Vladimir Ćirković`) fields.

## Social image and icons

The social image was generated by rendering a purpose-built 1200×630 HTML layout in the site's dark palette and exporting it as `og-image.png`. The hand-authored 64×64 `favicon.svg` is the icon source; it was rasterized into the 48/32/16 px images in `favicon.ico` and the 180×180 `apple-touch-icon.png`. Commit the exported assets themselves so deployment remains build-free.
